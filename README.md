# dynologger.turboloser.co

Static support site for the iOS app: landing page (`/`), `/support/`, `/privacy/` and `404.html`. No build step;
edit the HTML directly. Styling copies the Virtual Dyno's tokens, window and banner (`style.css`), and VT323 is
self-hosted in `fonts/` with its licence. `CNAME` is for GitHub Pages.

App Store Connect URLs: Privacy Policy `https://dynologger.turboloser.co/privacy/`,
Support `https://dynologger.turboloser.co/support/`, Marketing `https://dynologger.turboloser.co/`.

When the app is live, replace the "Coming soon" `.store` element in `index.html` with Apple's official
"Download on the App Store" badge linked to the listing.
